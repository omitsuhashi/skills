# Triage Labels

| Role | Label | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer の評価待ち |
| needs-info | needs-info | 追加情報待ち |
| ready-for-agent | ready-for-agent | 仕様が整い、Agent が実装可能 |
| ready-for-human | ready-for-human | Human による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが指定する role を、この表の label に対応付ける。
