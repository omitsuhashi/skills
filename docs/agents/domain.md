# Domain Docs

## Layout and reading rules

- single-context とする。
- 最初に `knowledge/AGENTS.md` を読み、`knowledge/index.md` から対象領域の用語・仕様・設計判断を参照する。
- 既存の `CONTEXT.md` / `CONTEXT-MAP.md` があれば参照する。
- 文書が存在しない場合、セットアップのためだけに作成しない。
- 新しい永続的なドメイン文書・ADR は `knowledge/AGENTS.md` に従い `knowledge/wiki/` 配下へ保存する。
- 既存文書で定義された用語を使用する。
- 既存の設計判断と矛盾する提案は、その矛盾を明示する。
